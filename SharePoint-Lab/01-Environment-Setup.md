# Lab 1 - Environment Setup (SharePoint)

## Objective
Set up a Microsoft 365 environment and access SharePoint Online.

## What is Microsoft 365?
Microsoft 365 is a cloud-based platform that provides productivity tools, identity management, and collaboration services.

## What is a Tenant?
A tenant is a dedicated instance of Microsoft 365 for an organization. It contains users, permissions, and services like SharePoint and Teams.

## Steps Performed
- Signed up for Microsoft 365 Developer Program
- Accessed Microsoft 365 Admin Center
- Navigated to SharePoint Admin Center

## Key Takeaways
- SharePoint Online is part of Microsoft 365
- Admin Center is used to manage users and services
- A tenant represents an organization in the cloud
